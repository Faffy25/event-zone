# EventZone - Event Booking Management System

Full-stack booking platform built at Techmasters Company, Lusaka.

Tech: PHP, MySQL, JavaScript, HTML5, CSS3
GitHub: github.com/Faffy25/event-zone
Author: BSc ICT Eden University

## Features
- User Login / Register
- Browse & Search Events
- Check Venue Availability
- Book & Manage Tickets
- Admin Dashboard
- Responsive Mobile UI

## What I Built
- Designed MySQL tables for users, events, venues, bookings
- Built PHP backend for auth and booking logic
- Made frontend with JS validation
- Tested and fixed bugs

## How to Run
1. Clone repo
2. Put in XAMPP htdocs
3. Import eventzone.sql in MySQL
4. Edit db.php with your DB password
5. Run localhost/event-zone
